### 01 — Steel Industry Energy Consumption

End-to-end industrial data-analysis and machine-learning project using Python, pandas, SQL, DuckDB, scikit-learn, and XGBoost to analyze and predict steel-industry energy consumption.

Topics practiced:

**Exploratory data analysis**

* pandas DataFrames
* data types and missing-value inspection
* descriptive statistics
* distributions and histograms
* scatterplots
* correlation analysis

**SQL and data querying**

* SELECT and filtering with WHERE
* sorting and aggregation
* GROUP BY and HAVING
* COUNT, AVG, MIN, MAX
* conditional logic with CASE
* INNER JOIN and LEFT JOIN
* common table expressions (CTEs)
* window functions
* ROW_NUMBER and PARTITION BY
* querying pandas DataFrames with DuckDB
* loading data into a DuckDB database table

**Machine learning**

* supervised regression
* feature and target selection
* train/test splitting
* reproducible experiments with `random_state`
* baseline model comparison
* Linear Regression and Ridge Regression
* L2 regularization and numerical feature scaling
* decision trees and regression trees
* Random Forest regression
* Gradient Boosting regression
* XGBoost regression
* scikit-learn `Pipeline` workflows
* `ColumnTransformer` for mixed numerical and categorical features
* categorical encoding with `OneHotEncoder`
* model-specific preprocessing pipelines
* leakage-safe preprocessing during cross-validation
* 5-fold cross-validation with `KFold`
* multi-metric validation with `cross_validate`
* training vs. validation performance comparison
* CV mean and standard-deviation analysis
* MAE, RMSE, and R² evaluation
* overfitting and data-leakage analysis
* feature sensitivity analysis for potential target leakage
* hyperparameter tuning with `GridSearchCV` and `RandomizedSearchCV`
* model benchmarking and selection
* held-out test-set evaluation
